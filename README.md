# BLAGO — личный бренд украшений из серебра

Сайт-витрина к практической работе №7: знак бренда и 12 изделий (сувенирная и презентационная продукция) в 3D.

- 3D: three.js, модели собраны в Blender (`blender/build.py` в исходниках проекта)
- Текстуры: ambientCG, CC0 (см. `assets/tx/SOURCES.txt`)
- Шрифты: UnifrakturMaguntia, Cormorant Garamond, Inter (Google Fonts, OFL)
